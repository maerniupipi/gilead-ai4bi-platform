# 帮助中心模块

## 功能概述

帮助中心是一个集成的用户文档和指南系统，帮助用户快速了解和使用系统的各项功能。

## 主要功能

### 1. 快速开始
- 引导用户完成系统核心功能的配置
- 提供步骤化的操作指南
- 包含示例截图说明

### 2. 模块帮助
按模块分类展示系统功能：
- **ChatBI 模块**：数据源配置、知识库管理、数据问答等
- **管理模块**：模型配置、存储管理、系统监控等
- **工作流模块**：工作流设计、工具管理、插件配置等
- **评测模块**：评测集管理、任务执行、结果分析等

### 3. 更新介绍
- 展示系统版本更新日志
- 支持按版本号、更新类型筛选
- 从数据库动态加载数据

### 4. 快速查找
- 全局搜索功能
- 支持按功能名称、描述搜索
- 快速定位到对应功能页面

## 配置说明

帮助内容目前集中维护在 `HelpCenterIndex.vue`，便于随页面结构同步调整。若后续内容膨胀，再拆分为独立配置模块。

## 后端API

### 获取更新日志

```
GET /api/system-updates/published
```

参数：
- `skip`: 跳过条数（默认0）
- `limit`: 每页条数（默认20）

### 获取更新详情

```
GET /api/system-updates/{id}
```

### 创建更新日志（管理员）

```
POST /api/system-updates/
```

请求体：
```json
{
  "version": "v1.2.0",
  "title": "更新标题",
  "content": "<p>更新内容</p>",
  "update_type": "feature",
  "release_date": "2024-04-01T10:00:00"
}
```

## 数据库迁移

运行迁移脚本创建更新日志表：

```bash
cd backend
python migrate_system_update.py
```

## 使用说明

### 添加新的帮助文档

1. 在 `HelpCenterIndex.vue` 中添加模块或子模块内容
2. 上传截图到 `public/images/help/` 目录
3. 在配置中引用截图路径

### 添加更新日志

1. 通过管理员API创建更新记录
2. 或直接在数据库中插入数据

### 自定义样式

帮助中心使用 Element Plus 组件库，可通过以下方式自定义：
- 修改 CSS 变量
- 覆盖组件样式
- 使用主题配置

## 扩展功能

### 添加新模块

1. 在 `HelpCenterIndex.vue` 中添加模块内容
2. 在 `HelpCenterIndex.vue` 中添加图标映射
3. 更新路由配置

### 添加多语言支持

1. 创建语言文件
2. 使用 Vue I18n 插件
3. 在配置中使用翻译键

### 添加视频教程

1. 上传视频到 CDN
2. 在配置中添加视频链接
3. 使用视频播放组件

## 注意事项

1. 截图建议使用 SVG 格式，支持缩放且文件较小
2. 更新内容支持 HTML 格式，注意 XSS 防护
3. 搜索功能基于前端实现，大量数据建议使用后端搜索
4. 管理员功能需要相应权限才能访问
