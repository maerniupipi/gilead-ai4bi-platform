## 交付内容

保留完整平台后端与前端、通用工作流和实验室、知识库与多列召回、模型和数据源管理、SQL 查询控制台、评测、会话管理、诊断和文件导出。Excel 批跑工具以通用接口配置独立提供。

服务入口为 `/api/service`，用户使用不透明标识，并按服务 Key 隔离会话、任务和完整结果。内置组织身份查询、客户专属授权接口、特殊身份回填、旧会话导入协议及相关 UI 已移除。工作流仍可显式接入业务扩展；SQL 转换工作流失败时不回退原 SQL。

移除引擎中的客户业务提示词、组织层级字段过滤和固定业务表规则。普通召回、历史问题窗口、工作流变量映射、通用外部 HTTP 节点与 SQL 改写步骤保留。同步调度、租约、进度与事务替换保留；数据源由部署配置提供，默认无任务。

导出使用两份新建的通用可编辑 PPT 模板，保留可编辑图表和表格。电子表格保留全量数据、公式文本保护和签名下载，清除客户身份水印实现。

部署只包含平台前后端、MySQL 与 Redis；没有旧环境网关、远端补丁或客户用户端依赖。数据库结构由当前 ORM 重新生成，共 68 张表；补齐系统更新模型在空库初始化前的注册。
